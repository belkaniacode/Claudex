# Claudex

> Удобное управление локальным claude-code-chatgpt-proxy из панели KDE Plasma.

**Claudex — не форк и не замена [claude-code-chatgpt-proxy](https://github.com/eugeny-dementev/claude-code-chatgpt-proxy).** Это отдельный виджет, который использует уже установленный прокси и добавляет удобное управление из панели рабочего стола: включение, выключение, состояние и последние сообщения журнала.

Сам прокси, подключение к провайдеру и авторизация остаются на стороне исходного проекта. Claudex не устанавливает и не настраивает их вместо вас.

## Зачем нужен

- Запускает прокси в фоне без постоянно открытого терминала.
- Показывает состояние в панели, а подробности и журнал — во всплывающем окне.
- Переключает настройки будущих запусков Claude Code на локальный GPT-прокси, а при выключении возвращает прежние настройки.
- Перед изменением настроек сохраняет защищённую резервную копию.
- Не включает автозапуск: прокси запускается только по вашему действию.

Это виджет **панели KDE Plasma**, который можно разместить рядом с системным треем, а не универсальное приложение для трея любого рабочего стола.

## Совместимость

| Система | Поддержка |
| --- | --- |
| Arch Linux с KDE Plasma 6 | Основная платформа разработки: Plasma 6.7.5, Wayland. |
| EndeavourOS, Manjaro и другие системы на базе Arch с Plasma 6 | Возможна установка при наличии тех же зависимостей и путей; отдельно не проверены. |
| Fedora KDE, Kubuntu, Debian KDE, openSUSE KDE | Нужны Plasma 6 и systemd. Текущий установщик содержит Arch-специфичную проверку пути Qt; установка без адаптации не гарантируется. |
| KDE Plasma 5, GNOME, Xfce и другие рабочие столы | Текущая версия виджета не поддерживается. |
| Windows и macOS | Текущая версия не поддерживается. |

Для других Linux-дистрибутивов недостаточно заменить команду пакетного менеджера: названия пакетов и расположение компонентов Plasma/Qt отличаются. Ниже приведён путь установки для Arch и совместимых систем; готовых проверенных инструкций для остальных пока нет.

## Перед установкой

1. Установите и настройте [claude-code-chatgpt-proxy по инструкции исходного проекта](https://github.com/eugeny-dementev/claude-code-chatgpt-proxy#readme).
2. Проверьте, что прокси запускается вручную и авторизация работает. По умолчанию Claudex ожидает его в `~/claude-code-chatgpt-proxy`, с подготовленным виртуальным окружением `.venv`.
3. Для переключения провайдера установите Claude Code. Claudex использует стандартные пользовательские настройки `~/.claude/settings.json` и существующий локальный ключ прокси.
4. Остановите вручную запущенный прокси, прежде чем включать его через виджет.

## Установка на Arch Linux и совместимых системах

Устанавливайте в обычной графической сессии KDE Plasma 6. Для установки самого виджета **не используйте sudo**; права администратора нужны только пакетному менеджеру.

Установите зависимости:

```sh
sudo pacman -S --needed git python systemd libplasma plasma-workspace plasma5support kpackage kirigami ki18n gettext glib2
```

Скачайте Claudex и перейдите в каталог проекта:

```sh
git clone https://github.com/belkaniacode/Claudex.git
cd Claudex
```

Проверьте условия установки без внесения изменений, затем запустите установщик:

```sh
/usr/bin/python3 -I -B scripts/install.py --dry-run
/usr/bin/python3 -I -B scripts/install.py
```

Если исходный прокси находится в другом каталоге, добавьте к обеим командам параметр `--proxy-dir /полный/путь/к/прокси`. При необходимости порт задаётся параметром `--port 4001`; он должен соответствовать настройкам самого прокси.

После установки откройте режим редактирования панели KDE → **Добавить виджеты** → найдите **Claudex** → перетащите его на панель. Установщик не добавляет виджет автоматически, не запускает прокси и не перезапускает рабочий стол.

## Как пользоваться

1. Нажмите значок Claudex на панели и включите прокси.
2. Дождитесь готовности локального сервиса, затем перезапустите Claude Code. В VS Code может потребоваться **Developer: Reload Window**.
3. Работайте в проекте без предварительного выполнения `source` и специального запуска редактора.
4. Выключите Claudex, чтобы восстановить прежние настройки, и снова перезапустите Claude Code.

Уже открытый чат не переключает провайдера на лету. Если VS Code ранее запускался из терминала с настроенным окружением прокси, полностью закройте его и откройте с рабочего стола. Настройки проекта, переменные окружения, удалённые сессии и контейнеры могут переопределять глобальные настройки.

Зелёный индикатор означает готовность управляемого локального сервиса, а не проверку авторизации, подписки, квоты или ответа модели. При ошибке авторизации смотрите подробности виджета и `/status` в Claude Code.

## Резервные копии и безопасность

Перед переключением Claudex сохраняет полную копию прежних настроек. При выключении восстанавливает только изменённые им поля, сохраняя посторонние правки. Конфликтующие изменения не перезаписываются автоматически.

Копии находятся в `~/.config/cloudegpt-proxy-widget/profile-backups/` при стандартных настройках XDG. Каталог доступен только владельцу; копии сохраняются и после восстановления. Они могут содержать прежние секреты — **не публикуйте их в Git и не отправляйте вместе с журналами**.

Ключ шлюза не копируется в настройки Claude Code: он передаётся через вспомогательную команду авторизации. Claudex не изменяет исходники, виртуальное окружение или файлы учётных данных исходного прокси.

## Обновление и удаление

Перед обновлением выключите Claudex и дождитесь восстановления прежнего профиля. Обновите исходники через `git pull --ff-only` и повторите команду установки. Если Plasma продолжает показывать старый интерфейс, выйдите из сеанса и войдите снова, предварительно сохранив работу.

Для удаления сначала выключите прокси через Claudex, затем уберите виджет с панели и выполните:

```sh
/usr/bin/python3 -I -B scripts/uninstall.py --dry-run
/usr/bin/python3 -I -B scripts/uninstall.py
```

Исходный прокси, его учётные данные и резервные копии настроек сохраняются.
